# Voyage3D - Mesmerizing 3D Travel Agency Website

Welcome to Voyage3D, a revolutionary travel agency website featuring mesmerizing 3D navigation and immersive travel experiences. Built with the latest tech stack and easily deployable on Vercel.

## 🚀 Features

- **Mesmerizing 3D Navigation**: Interactive 3D navigation system using Three.js and React Three Fiber
- **Immersive Travel Experience**: Explore destinations in stunning 3D environments
- **Modern Tech Stack**: Next.js 14, React, Three.js, Framer Motion, Tailwind CSS
- **Responsive Design**: Works seamlessly on all devices
- **Performance Optimized**: Optimized for fast loading and smooth interactions
- **Vercel Deployable**: Ready for one-click deployment on Vercel

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **3D Library**: Three.js with React Three Fiber and Drei
- **Animations**: Framer Motion for smooth animations
- **Styling**: Tailwind CSS with custom animations
- **State Management**: React Hooks
- **Deployment**: Vercel

## 📁 Project Structure

```
├── app/
│   ├── layout.js          # Root layout with global styles
│   ├── page.js           # Home page with 3D navigation
│   ├── destinations/     # Destinations page

├── components/          # Reusable components
├── public/             # Static assets
├── package.json        # Dependencies and scripts
├── next.config.js      # Next.js configuration
├── tailwind.config.js  # Tailwind CSS configuration
├── postcss.config.js   # PostCSS configuration

```

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Open Your Browser**:
   Visit [http://localhost:3000](http://localhost:3000)

## 📦 Deployment

### Deploy on Vercel

The easiest way to deploy this application is to use Vercel, the creators of Next.js:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/voyage3d&project-name=voyage3d&repository-name=voyage3d)

### Manual Deployment

1. Build the application:
   ```bash
   npm run build
   ```

2. Start the production server:
   ```bash
   npm start
   ```
